## 1. Game Overview
Game1WithC is a 2D bullet-hell shooting game developed using C++ and SDL2. The game adopts a classic shooting style where players control a spaceship to navigate through space and fire rockets to defeat enemies.
This is a free and open-source game project, developed entirely based on the C++17 standard. It utilizes a modern game architecture design, including singleton patterns and a scene system, providing players with a smooth gaming experience.

## 2. Gameplay Objective
Players control a spaceship to move freely in space and obtain points by destroying enemies with fired rockets. The challenge of the game lies in dodging enemy attacks while defeating as many enemies as possible.
This is a free game; if anyone charges for downloading this game, it is a scam.

## 3. Game Controls
- **WASD Keys** - Control spaceship movement
- **E Key** - Fire rockets to attack enemies
